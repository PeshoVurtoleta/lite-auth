Serve this demo over HTTP

The demo loads lite-auth as an ES module, which browsers block over file://. From the package root run any static server and open the printed URL:

npx serve demo

Cross-tab logout and shared persistence also require a real origin, so http is needed to see those anyway. Then open the page in two tabs and sign out in one.
